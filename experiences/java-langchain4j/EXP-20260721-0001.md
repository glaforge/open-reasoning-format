## 1. Objective
Provision and build a Java Maven project using LangChain4j to invoke Google Gemini models cleanly.

## 2. The Trap
Agents frequently target obsolete Java versions (<17), use legacy or missing Maven compiler source/target settings, reference deprecated artifact IDs (e.g. `langchain4j-vertex-ai`), or hardcode outdated model names (such as `gemini-1.5-flash`, `gemini-2.0-flash`, `gemini-pro`, or `gemini-1.0-pro`), causing build failures, outdated model usage, or API deprecation errors.

## 3. Abstracted Insight
> **Core Principle:** Always target Java 17+ in `pom.xml`, use dependency `dev.langchain4j:langchain4j-google-genai`, and specify a modern Gemini model identifier such as `gemini-2.5-flash` or `gemini-flash-latest`.

## 4. Validated Path
Configure `pom.xml` with Java 17+ compiler properties and `dev.langchain4j` dependencies:

```xml
<properties>
    <maven.compiler.source>17</maven.compiler.source>
    <maven.compiler.target>17</maven.compiler.target>
</properties>

<dependencies>
    <dependency>
        <groupId>dev.langchain4j</groupId>
        <artifactId>langchain4j-google-genai</artifactId>
        <version>1.18.0-beta28</version>
    </dependency>
</dependencies>
```

Instantiate the chat model with `gemini-3.5-flash`, `gemini-3.1-flash-lite`, `gemini-2.5-flash` or `gemini-flash-latest`:

```java
ChatLanguageModel model = GoogleAiGeminiChatModel.builder()
    .apiKey(apiKey)
    .modelName("gemini-3.5-flash")
    .build();
```

## 5. Verification Checklist
- [ ] Verify `pom.xml` targets Java 17 or higher.
- [ ] Confirm dependency artifact `dev.langchain4j:langchain4j-google-genai`.
- [ ] Ensure model identifier is `gemini-3.5-flash`, `gemini-3.1-flash-lite`, `gemini-2.5-flash` or `gemini-flash-latest`.
