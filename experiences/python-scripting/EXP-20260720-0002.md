## 1. Objective
Write or update a persistent file on disk cleanly so that readers never observe zero-byte or partially written content, even if the program or system crashes mid-operation.

## 2. The Trap
Opening a target file directly with `open(file_path, 'w')` immediately truncates the existing file on disk to 0 bytes before writing new data. If an uncaught exception, power loss, or SIGINT occurs during `write()`, the original data is destroyed and replaced by corrupted or empty data.

## 3. Abstracted Insight
> **Core Principle:** Write to a named temporary file in the same directory, flush and sync file descriptors to disk, and perform an atomic filesystem replacement (`os.replace`).

## 4. Validated Path
Create a temporary file in the destination directory using `tempfile.NamedTemporaryFile`, write data, call `flush()` and `os.fsync()`, and perform `os.replace(temp_path, target_path)`.

```python
import os
import tempfile

def atomic_write(target_path, content):
    dir_name = os.path.dirname(os.path.abspath(target_path))
    os.makedirs(dir_name, exist_ok=True)
    
    with tempfile.NamedTemporaryFile("w", dir=dir_name, delete=False, encoding="utf-8") as tf:
        temp_name = tf.name
        tf.write(content)
        tf.flush()
        os.fsync(tf.fileno())
        
    os.replace(temp_name, target_path)
```

## 5. Verification Checklist
- [ ] Verify temporary file is created in the exact same filesystem directory/volume.
- [ ] Confirm `os.replace` replaces target without creating leftover `.tmp` files.
- [ ] Ensure target file is never left empty or partial if exception occurs before `os.replace`.
