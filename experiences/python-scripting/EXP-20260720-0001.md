## 1. Objective
Parse and dynamically append items to a Markdown document that uses YAML frontmatter metadata blocks without destroying or invalidating the frontmatter header.

## 2. The Trap
Using basic string replacement or naive file appending causes the YAML frontmatter section (`---` block) to be appended to or corrupted, breaking metadata parsers that expect frontmatter at the very top of the file.

## 3. Abstracted Insight
> **Core Principle:** Always split Markdown documents on frontmatter delimiters (`---`) into structured metadata and content body before performing mutating operations.

## 4. Validated Path
Split the document content with `content.split("---", 2)`, parse the second element (`parts[1]`) with PyYAML, update the document body (`parts[2]`), and reassemble the document sequentially.

```python
parts = content.split("---", 2)
if len(parts) >= 3:
    frontmatter = yaml.safe_load(parts[1])
    body = parts[2]
```

## 5. Verification Checklist
- [ ] Verify that frontmatter remains at the exact beginning of the file starting with `---`.
- [ ] Confirm `yaml.safe_load()` parses the frontmatter without syntax errors.
